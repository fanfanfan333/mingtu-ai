# 明途 AI v0.1 测试计划

## 单元测试（test/，纯 Dart 核心逻辑）

- task_manager_test.dart：合法流程、非法迁移不改变状态、紧急状态不自动恢复导航、已完成状态只能显式重置。
- speech_scheduler_test.dart：高优先级打断直行、恢复需重新确认并重启计时器、过期指令丢弃、同一事件去重。
- risk_engine_test.dart：侧方不确定时不给左右步数、漏检时不给安全结论、侧方已确认且空间证据充分时可给步数、冲突步数方向解析为停下、过期事件无效。
- route_scoring_test.dart：无障碍未知成本为 1.0 且不优于同条件的可通行路线、权重归一化后风险权重高时更安全的长路线胜出。
- llm_gateway_test.dart：本地未尝试时拒绝云端调用、预算上限超支时拒绝、国外高价模型 id 被拒绝。
