# 明途 AI 功能可行性评估（v0.4，2026-11-05）

评估口径：比赛版只做校园图书馆一个完整场景、预算很低人民币、
云端只在 VM 内验证、真机一步还没做。凡是“能写代码但不能在真机上
验证安全”的功能，一律不算已实现。

## 结论总表

| 总规范功能 | 结论 | 本版本做法 |
|---|---|---|
| 语音控制（暂停/继续/取消/再说一遍/状态/帮助/紧急） | 可做，已做 | 指令解析 + 调度器，见 v0.2.2 |
| 持续唤醒词“小途”一直监听 | 不可做（本版） | **删除**，替代：应用内语音控制 + 指令解析；`voice_io.dart` 的 `wakeWordStatus` 明写 NOT_IMPLEMENTED |
| 统一任务管理器、状态机 | 可做，已做 | v0.3 加 `preparing`/`executing`；v0.4 加 `TaskContext.fromTaskManager` 单一快照 |
| 统一事件总线、统一合同、健康监控 | 可做，已做 | v0.3；v0.4 演示开始时上报地图桩/演示语音/无摄像头 |
| 实时感知：YOLO 检测 + 跟踪去重逻辑 | 逻辑可做，真机不可验证 | 接口 + 跟踪 + 去重已做；v0.4 加低置信度过滤（<0.3 不建轨迹）与过期轨迹计数；模型文件与手机推理仍 NOT_IMPLEMENTED |
| 盲道视觉识别（从图里认盲道） | 不可用通用 YOLO 做 | 替代：规则评估（可见/被占/替代是否确认），侧方未确认不给步数 |
| 风险引擎、语音调度器 | 可做，已做 | v0.4 加：交通/位置不确定永不给步数；转弯与避障冲突指令直接丢弃不连播 |
| 地图导航：高德 SDK 真实接入 | VM 内不可验证，无 Key | 替代：桩路线 + 路线评分（UNKNOWN 永不记安全）+ 接近切换；v0.4 加偏航重规划条件（偏航且精度 ≤30 米才重规划） |
| 路口过街决策（信号灯 = 可以过马路） | **删除，无可接受替代** | 替代（不是放行）：`traffic_scene.dart` 只提示、不放行，`allowsCrossing` 恒为 false；Skill 改为 `traffic_scene_info` |
| 云端大模型：文本规划 | 可做，文本已做 | 百炼文本客户端，网关 + 预算；真实调用与计费仍需用户本机验证 |
| 云端视觉：上传摄像头画面给模型 | 不可做（本版） | **删除**，`BailianClient.callVision` 恒返回 NOT_CONFIGURED，零网络请求，有测试 |
| Skill 系统 | 可做，已做 | 注册表 13 个；v0.4 演示路线规划走注册表门禁 |
| 目的地入口寻找 | 逻辑可做，真实数据待核验 | 占位不能确认入口；演示已核验候选不是真实地点 |
| 室内任务：图书馆服务台 | 可做，已做 | 需证据才推进 |
| 室内任务：医院完整挂号（含缴费/身份） | 不可做 | 替代：前置三步，`isFullyCompleted` 恒 false，永不算挂号成功 |
| 室内任务：车站 | 无场景数据，不可做 | **删除**：不注册、不写占位 Skill，见注册表 |
| 紧急求助：本地流程 | 可做，已做 | 不依赖网络/大模型，永不宣称已联系 |
| 紧急求助：呼叫附近残疾人帮助站 | 无核验名录、无真实拨打 | **删除已实现宣称**：保留为未来需求，当前只给本地流程 + 备用方案 |
| 录像管理：本地会话保留/删除 | 可做，已做 | 等用户选择；删除只针对本地会话 |
| 录像保存到手机相册 | VM/网页不可验证，无相册插件 | **删除已实现宣称**：`RecordingManager.albumExportStatus` 明写 NOT_CONFIGURED，本地保存 ≠ 存入相册 |
| 持续学习：自动改生产安全规则 | 不可做，且被禁 | **删除**，替代：`learning_backlog.dart` 只记录、永不自动应用，无 `apply()` 方法 |
| 系统健康与降级 | 可做，已做 | v0.4 演示上报真实降级状态 |

## 被删除的功能清单（必须在提交材料里照实写）

1. 持续唤醒词一直监听。
2. 路口过街决策 / 信号灯放行。
3. 云端视觉传图。
4. 车站场景 Skill。
5. 医院完整挂号（缴费、身份核验）。
6. 呼叫附近残疾人帮助站（作为已实现功能）。
7. 保存录像到手机相册（作为已实现功能）。
8. 持续学习自动改安全规则。

以上删除不是“以后一定不做”，而是“本版不宣称、不实现、不留一个看起来能用
的假入口”。其中 2、3、8 有替代（只提示 / 只发文本 / 只记录），其余
目前没有可验证的替代，所以直接删，不留占位。

## 仍未验证（删了假功能不等于真功能已验证）

真机运行、真实系统 ASR/TTS、摄像头、GPS、高德、YOLO、实地核验地点、
真实道路安全、真实盲人用户实测、真实百炼调用与计费。
