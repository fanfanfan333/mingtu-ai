# 明途缺陷清单：已补 vs 仍开放（盲人第一）

盲人第一的意思是：先补“用户听不到、停不下来、重复不了、走错了没人管”
这类缺陷，再补其他功能。能补的先在代码里补，不能在云端验证的
不冒充已补，列在“仍开放”里，等真机那一步。

## v0.2.2 已补（代码 + 测试，云端可验证）

1. 没有语音控制：补了 `lib/core/voice_commands.dart`。
   支持：带我去图书馆、暂停、继续、取消、再说一遍、现在到哪了、
   帮助、我需要帮助。非法迁移只回答，不静默执行；紧急永不自动恢复导航。
2. 停不下来 / 恢复就乱走：语音暂停会停直行计时器并清掉直行提示；
   语音继续只回到导航状态，不自动重启直行，必须重新确认直行路段。
3. 听漏了没法重听：主界面记住上一条已播报提示，“再说一遍”会重新提交它。
4. 不知道走到哪了：语音“现在到哪了”会播报当前任务状态 + 当前提示。
5. 听不清怎么办：无法识别的指令不猜，会播报可说指令列表。
6. 医院挂号只有一句占位：补了 `lib/modules/hospital_task.dart` 的
   前置引导三步（找挂号处、读机器说明、确认排队位置），每步都要核验
   才能前进。但缴费 / 身份核验仍未实现，所以 `isFullyCompleted`
   永远是 false，绝不能把前置步骤说成挂号成功。
7. 语音输入输出没有合同：补了 `lib/adapters/voice_io.dart`，
   明确系统 TTS / ASR 还没接入，当前实现只报 NOT_CONFIGURED，不假装会说话。

## 仍开放（云端做不出来，必须真机那一步，不算已补）

- 真实系统 TTS / ASR 接入：要接手机系统语音合成和识别插件，
  并走无障碍设置，不能用绕过无障碍的自定义音频方案代替。
- 真实摄像头、GPS / 定位、连续感知帧循环：现在只有单帧跟踪去重逻辑。
- 高德 SDK 真实接入：现在是桩路线，候选路线和距离都不是真实地图结果。
- 本地 YOLO 模型文件 + 手机端推理延迟：现在只有接口和跟踪逻辑。
- 红绿灯判断、精确测距、车辆速度方向判断：现在明确不做，单张图不能下结论。
- 真实医院缴费、身份核验、真实帮助站联系：现在一律不宣称已联系、已完成。
- 实地核验地点、真实道路安全验证、真实盲人用户实测：等实地核验单填回来、
  在受控校园环境走一遍后才能改状态。

## 验收口径

- “已补” = 代码已写 + 测试已过 + 云端 analyze / test / build web 已过。
- “仍开放” = 即使代码里有接口，也只能写 NOT_CONFIGURED / NOT_IMPLEMENTED，
  不能在提交材料里写成已实现、已测试、已现场验证。
