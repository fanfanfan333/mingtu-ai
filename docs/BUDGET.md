# 明途 AI v0.1 预算

## 上限

**总上限：100 元人民币。** 目标实际花费 20 到 50 元，能用免费额度先用免费额度。

## 预算原则

- 本地优先：本地 YOLO、本地 OCR、系统语音、本地规则不花云端费用。
- 云端按需：云端只在本地不足的触发点调用一次，不做连续视频流，不做全程大模型导航。
- 轻量模型：国内 Flash / Lite 级模型，模型 id 可配置，网关拒绝 Claude、GPT、Gemini 等国外高价模型 id。
- 硬上限：云端网关的 budgetCapRmb 默认 100 元，预估费用加已花费超过上限时拒绝调用，调用方必须本地降级。
- 不花钱的项：Flutter 开源、预训练 YOLO 模型文件（需确认许可证）、系统 ASR/TTS、本地 JSON 地点数据、现有手机与挂绳。

## 估算（不是官方报价）

- 云端视觉与文本（开发测试加演示）：预留 10 到 20 元。按轻量模型量级估算，单次关键帧调用约 0.001 元量级，演示调用数百次仍在个位数元内；最终以各家控制台实际单价为准。
- 编程辅助（如用国内低价编程模型）：上限 30 元，一次只做一个模块，连续修复失败达到设定次数即停，不得自动循环。
- 地图、本地模型、系统语音、服务器：0 元（地图以控制台免费额度为准，超出前必须停用或降级）。
- 预留应急：10 元。
- 硬件、智能眼镜、GPU 训练、服务器租赁：0 元，不在 v0.1 范围内。

## 容易超支的风险

真正容易超支的不是演示调用，而是编程模型反复改代码和把每一帧都上传云端。v0.1 通过本地优先、按需触发、任务拆分、失败即停、预算硬上限五条规则控制这两项。

## 记账要求

每次云端调用都必须记录：调用类型、原因、本地是否不足、预估费用、实际费用、剩余预算。没有记账的调用不得计入“预算内”的说法。
