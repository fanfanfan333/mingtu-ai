# 明途 AI 技术债（重构第一阶段，2026-11-05）

技术债 = 已知但还没还的账，不是已修复的记录。已修复的见 `docs/DEFECTS.md`。

## 必须在真机那一步还的债（云端做不出来）

1. 真实系统 ASR/TTS：现在只有演示文本与模拟输入。
2. 真实摄像头、GPS、连续感知帧循环：现在只有单帧跟踪去重逻辑。
3. 高德 SDK 真实接入：现在是桩路线，距离不是真实地图结果。
4. 本地 YOLO 模型文件 + 手机端推理延迟：现在只有接口。
5. 红绿灯判断、精确测距、车辆速度方向判断：现在明确不做，单张图不能下结论。
6. 真实医院缴费、身份核验、真实帮助站联系：一律不宣称。
7. 实地核验地点、受控校园实测、真实盲人用户实测：等核验单填回后才能做。

## 架构债（本阶段已部分还，剩下的留给下一阶段）

1. 统一层已建，但旧模块还没有全部改成“只通过事件总线和合同对外通信”——本阶段只接了语音播报事件和紧急事件，其余模块的事件发布是下一阶段的工作，不能在本阶段宣称“全部模块已统一”。
2. `main.dart` 演示入口仍是演示流程的编排者，任务状态机之外的演示状态（如直行确认、风险激活）仍由界面持有，下一阶段应收进统一任务上下文。
3. 事件总线与健康监控的演示重置不清空历史：重置演示会新建任务与调度器，但事件总线与健康监控是界面级常量，会保留旧事件与旧健康报告。演示时以当前任务事件为准，不把旧事件当作当前状态。
4. Skill 注册表目前只做注册与门禁，Skill 的版本管理、评估、回滚、离线测试生成还没做；持续学习不自动改生产安全规则，这条红线不变。
5. 视觉传图还没做：百炼客户端现在只发文本，摄像头画面不上传云端（这既是限制，也是隐私保护）。

## 不算债的东西

- “功能不够全面”不算债：比赛版只做校园图书馆一个完整场景，是有意压缩的范围，不是遗漏后补的借口。
- “没做智能眼镜、服务器、多场景”不算债：这些在预算与时间计划里本来就是延后项。
