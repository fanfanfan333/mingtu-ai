# 明途 AI v0.2：3 分钟演示脚本（校园图书馆场景）

> 演示目标：用一个完整、可重复的短流程证明任务状态机、语音调度、
> 风险引擎和任务验证是真实代码在跑，而不是口头描述。
> 演示地点是占位场景，不是真实地点。地点数据全部是“待现场核验”，
> 演示中出现的“演示用已核验入口”只是演示数据，不是真实地点。
> 本演示在网页 / 虚拟机中是模拟流程，不是真实传感器导航，
> 不能用于真实道路，也不能替代盲杖、导盲犬或专业定向行走训练，
> 也未经过真实道路安全验证。

## 准备（30 秒，不计入 3 分钟演示）

1. 运行应用，确认顶部写着：语音是主要交互方式，本页面是演示辅助界面，
   当前是模拟流程。
2. 确认配置状态栏：地图、YOLO、云端模型未配置时应显示
   NOT_CONFIGURED，应用不会伪造路线、检测或云端结果。
3. 确认当前任务状态为 idle，当前提示为“尚未开始”。

## 第 1 分钟：开始、规划、导航

1. 点“语音开始（演示输入：带我去图书馆）”。
   应看到：状态变为 understanding，提示为“已听到：带我去图书馆。
   演示输入，不是真实语音识别。”，日志写明这是演示输入。
   模拟的是语音输入，真实语音识别尚未接入。
2. 点“理解并规划路线”。
   应看到：已选路线、距离、得分和一句“无障碍信息均为 UNKNOWN，
   未按安全处理”。真实地图 SDK 尚未接入，路线是接口占位候选的评分结果。
3. 点“开始导航（直行节奏启动）”。
   应看到：状态变为 navigating，提示为“直走”，日志写明
   3 秒直行节奏已启动。等待约 3 秒，应再次听到/看到“直走”。
   点“直行提示（手动）”：在 3 秒间隔内应不重复播报，
   日志应说明调度器不重复播报。

## 第 2 分钟：转弯、两种障碍

1. 点“前方转弯（暂停直行）”。
   应看到：提示变为转弯，直行节奏已暂停。不要在转弯时继续说“直走”。
2. 点“重新确认直行路段并恢复”。
   应看到：已重新确认直线路段与导航版本，计时器已重启，
   旧直行指令没有被补播。
3. 点“模拟障碍：侧方未确认（应停下，不给步数）”。
   应看到：状态变为 avoidingObstacle，提示为停下类提示，
   障碍栏写明原因 uncertain-side-space、步数方向 none，
   明确写着“未给出左右步数”。这是本演示最关键的安全点：
   侧方未确认时，系统宁可停下，也绝不猜方向。
4. 点“障碍已移开，重新评估并恢复直行”。
   应看到：回到 navigating，直行恢复需重新确认。
5. 点“模拟障碍：侧方已确认（仅演示数据给一步）”。
   应看到：提示为“前方有障碍，已确认右侧有可通行空间。向右移动一步”，
   同时障碍栏写明“播报完成不等于动作完成”。
   这一步只在演示数据确认侧方时才成立，不是真实空间测量。
6. 点“动作后重新感知，确认后恢复导航”。
   应看到：重新感知后才恢复导航，而不是播报一结束就自动认为已绕过。

## 第 3 分钟：接近、入口、室内、完成、紧急与录像

1. 点“模拟行进至接近目的地”。
   应看到：演示推进后切换到 findingEntrance，
   并写明“地图显示接近不等于已找到入口”。
   真实定位与行进尚未接入，这是演示推进。
2. 点“寻找入口（先看占位，再看演示已核验候选）”。
   应看到两条结果：占位候选只能是 candidateFound，不能确认；
   演示用已核验候选才给出确认。演示候选不是真实地点，
   真实入口必须用现场核验数据替换。
3. 点“进入室内引导”，再点“室内步骤：用演示证据推进”三次。
   应看到：找到服务台、读取标识、确认到达依次推进，
   每一步都写明是演示证据。没有证据时步骤不得推进。
4. 点“验证任务”，再点“确认任务完成”。
   应看到：任务进入等待确认，再变为 completed，
   录像进入等待保留/删除选择。流程走完不等于任务成功，
   是验证步骤确认后才算完成。
5. 点“保留录像（本地）”或“删除录像（本地）”二选一。
   应看到：只处理本地演示会话；删除时不宣称已删除系统外的副本。
6. 点“云端网关演示”。
   应看到：未配置模型 ID 时为 NOT_CONFIGURED，不调用云端；
   已配置时只显示网关决策，明确写着“未产生真实网络调用和费用”。
7. 任意一步点“紧急求助（本地，不依赖网络和大模型）”。
   应看到：普通导航暂停，状态进入 emergency，
   并明确写着“未宣称已联系帮助站”，同时给出备用求助方式。
   紧急后不能自动恢复导航，必须重置演示重新开始。

## 演示结束时必须说清的三句话

1. 本演示跑的是真实核心逻辑（状态机、语音调度、风险引擎、
   路线评分、网关决策），但感知、定位、地图、语音识别合成
   在本机上是模拟或接口，不是真实传感器结果。
2. 地点数据是占位，真实演示必须先做现场核验。
3. 明途是辅助工具，不能替代盲杖、导盲犬或专业定向行走训练，
   未经过真实道路安全验证，不能用于真实道路导航。

## 演示中模拟与真实的对照表

| 环节 | 演示中是什么 | 真实手机上还需要什么 |
|---|---|---|
| 语音输入 | 按钮模拟的演示输入文本 | 系统语音识别接入与测试 |
| 直行/转弯/障碍提示 | 调度器真实输出的提示文本 | 系统 TTS 接入、真机播报测试 |
| 路线 | 接口占位候选的评分结果 | 高德密钥与真实步行路线接入验证 |
| 障碍感知 | 按钮模拟的检测帧与跟踪去重 | YOLO 模型文件与手机端推理验证 |
| 定位与行进 | 演示推进的剩余距离 | GPS/定位精度与偏航验证 |
| 入口与室内 | 演示候选与演示证据 | 现场核验的地点数据与标识测试 |
| 紧急求助 | 本地流程与备用方式文本 | 真实联系渠道与失败处理验证 |
| 录像 | 本地演示会话状态 | 真实录像采集、存储与删除验证 |
