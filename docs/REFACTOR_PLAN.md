# 明途 AI 重构计划（总规范的第一阶段，2026-11-05）

总规范要求“不做到这么全面，但盲人功能不能弱”。所以重构分阶段，
第一阶段只做“统一”，不扩场景、不加新能力、不改盲人优先规则。

## 第一阶段（本批，v0.3）：统一层，不破坏现有代码

- [x] 审计：`docs/CODE_AUDIT.md`、`EXISTING_MODULE_MAP.md`、`TECHNICAL_DEBT.md`。
- [x] 统一合同 `lib/core/contracts.dart`：任务上下文、环境事件、导航指令、用户同意。
- [x] 统一事件总线 `lib/core/event_bus.dart`：去重、过期丢弃、旧版本丢弃。
- [x] 健康监控 `lib/core/health_monitor.dart`：降级播报文案，空健康不报问题。
- [x] Skill 注册表 `lib/skills/registry.dart`：12 个真实 Skill，车站/交通场景不注册。
- [x] 任务状态机新增 `preparing`、`executing`，旧流程兼容，紧急不自动恢复不变。
- [x] 演示入口接线：语音播报发布 `speechRequested` 事件，紧急发布 `emergencyTriggered` 事件并上报本地紧急服务健康；界面显示系统健康状态。
- [x] 测试与构建：2026-11-05 VM 内实测，`flutter analyze` 无问题，`flutter test` 35/35，`flutter build web` 成功（构建产物不提交，未在浏览器中点按验证）。
- [ ] 推送：用户在场确认后推 main，核验远端头并回读新文件后才算推完。

## 第二阶段（v0.4 已做其中一部分，其余仍在下一批）

1. 地图、感知、风险、语音模块全部经事件总线发布状态，不再各持一份“当前状态”。（未全做完，不宣称）
2. 演示界面持有的直行确认、风险激活收进统一任务上下文。（未全做完；v0.4 只加了任务上下文快照）
3. Skill 执行结果经事件总线回写任务状态，高风险 Skill 仍需风险确认。（v0.4 已做：演示路线规划走注册表门禁）
4. 健康监控覆盖定位、摄像头、地图、云端网关的真实降级上报（只报真实状态，不伪造）。（v0.4 已做：演示开始上报地图桩/演示语音/无摄像头）

## 第三阶段（比赛前收尾，不扩范围）

1. 实地核验单填回 → 替换 `verified_locations.json` 占位，仍保留未填点为“待现场核验”。
2. 真机一步：用户本机跑 `flutter run` + 百炼真实调用 + 受控校园演示录像。
3. 提交材料：架构、测试报告、AI 应用说明文档、已实现/已测试/未实现诚实清单。

## 不做的事（本阶段明确排除）

- 不新增医院完整挂号、车站、交通灯过街、多场景、智能眼镜、服务器。
- 不让持续学习自动改安全规则；不让大模型直接决定每帧避障步数。
- 不把 IMPLEMENTED 自动标成 TESTED，更不标成 FIELD_VALIDATED。
- 不推未经验证的代码；不把云端通过说成真机通过。
