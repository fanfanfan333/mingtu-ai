# 明途 AI v0.1 模块接口

## 任务状态机（lib/core/task_manager.dart）

- 输入：显式迁移请求（目标状态、触发原因）。
- 输出：成功或拒绝；拒绝时状态不变，拒绝记录在 rejectedAttempts。
- 禁止：从自由文本推断状态；紧急状态直接回到导航状态；已完成、已失败、已取消状态未经显式重置回到其他状态。

## 语音调度器（lib/core/speech_scheduler.dart）

- 输入：SpeechRequest（事件 id、文本、类型、优先级、创建时间、过期时间、导航状态版本、是否要求直线路段）。
- 输出：当前播报项、已播报日志、被打断日志、过期丢弃日志、重复丢弃日志。
- 规则：所有模块只能提交，不能直接调用 TTS；过期请求丢弃；同一事件 id 未过期不重复；高优先级打断低优先级；直行恢复必须重新确认直线路段、无风险、导航版本未变，并重启 3 秒计时器。

## 风险引擎（lib/core/risk_engine.dart）

- 输入：RiskEvent（类型、感知证据、创建时间、过期时间）。
- 感知证据必须同时包含检测置信度和空间置信度、是否有距离估计、侧方空间是否确认、已确认的安全侧。
- 输出：RiskAssessment（等级 R0-R4、动作、语音文本、步数方向或无、是否有效、原因）。
- 规则：侧方未确认时步数方向为空，动作为停下；漏检时不返回继续；过期事件无效；冲突步数方向解析为停下。

## 路线评分（lib/core/route_scoring.dart）

- 输入：候选路线列表（距离、时间、无障碍状态、已知风险、数据可信度）和权重。
- 输出：按分数升序排列的路线，分数越低越优先；附选择原因。
- 规则：无障碍未知成本为 1.0，绝不为 0；数据可信度不是安全概率。

## 云端网关（lib/core/llm_gateway.dart）

- 输入：调用类型、原因、是否已尝试本地、本地是否不足、预估费用、输入负载。
- 输出：允许或拒绝及原因；允许时给出请求负载，网关本身不发网络请求。
- 规则：本地未尝试则拒绝；本地已够则拒绝；预估费用加已花费超过预算上限则拒绝；模型 id 含 Claude、GPT、Gemini、Opus 等子串时构造即拒绝。

## 地图接口（lib/modules/map_navigation.dart）

- 输入：起点、终点标签；位置点与定位精度。
- 输出：候选路线、导航状态、是否偏离、是否切换到目的地接近模式。
- 状态：接口加占位实现，未验证的高德集成，详见文件内注释。

## 本地感知（lib/modules/visual_perception.dart）

- 输入：一帧检测结果（标签、置信度、归一化中心坐标）。
- 输出：仅新跟踪目标和显著移动目标的事件；同一静止目标的重复帧输出为空。
- 状态：检测与跟踪接口已实现，YOLO 模型文件与手机端推理未实现。

## 盲道、入口、室内、紧急、录像

- 盲道：输入盲道是否可见、是否被占用、替代通道是否确认；被占用且替代未确认时返回停下。
- 入口：输入候选入口（是否现场核验、置信度）和定位精度；占位数据 alone 不能确认入口。
- 图书馆室内任务：输入每一步的验证证据；无验证不前进。
- 紧急：输入触发类型和位置（可选）；输出本地任务已创建、未宣称联系成功、备用方案列表。
- 录像：输入开始、停止、保存、删除操作；输出受管理的本地会话状态，不宣称系统外副本已删除。
