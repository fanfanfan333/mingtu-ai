# 明途 AI v0.1 提交清单（截止：11 月 10 日前完成，11 月 11 日前提交）

## 提交前必须确认

- [ ] 比赛官方截止时间、赛道要求、作品形式要求已再次核对（本仓库不替官方背书截止时间）。
- [ ] 场景已冻结为校园图书馆一条短路线，不再加新功能。
- [ ] 占位地点数据已替换为现场核验数据，或在材料中明确标注为占位、未核验。
- [ ] 提交材料中已实现、已测试、已现场验证、未实现四栏分开写。

## 提交物

- [ ] 可运行演示（应用或受控环境演示视频，视频必须标注受控环境演示，不是真实道路验证）。
- [ ] 架构说明（docs/SYSTEM_ARCHITECTURE.md）。
- [ ] 模块接口说明（docs/MODULE_CONTRACTS.md）。
- [ ] 安全要求与已知限制（docs/SAFETY_REQUIREMENTS.md、README.md）。
- [ ] 测试报告：附 scripts/run_tests.sh 的实际运行输出；未运行的测试明确写未运行。
- [ ] AI 应用说明文档：说明所用工具、使用环节、人机协作模式（按赛道要求补齐，工具清单不得虚构未接入的服务）。
- [ ] 预算说明（docs/BUDGET.md，实际花费以控制台账单为准）。

## 不得提交的内容

- [ ] 不得把医院挂号完整流程写成已实现。
- [ ] 不得把高德集成写成已验证（本版本只是接口加占位）。
- [ ] 不得把本地 YOLO 手机端推理写成已验证（模型文件与真机推理未实现）。
- [ ] 不得把模拟结果、演示成功写成真实场景验证。
- [ ] 不得删除“不能替代盲杖、导盲犬或专业训练”这句声明。
