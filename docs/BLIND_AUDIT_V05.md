# 明途 AI 盲人优先再审计（v0.5，2026-11-05）

本次审计只问一个问题：一个看不见屏幕的盲人用户，用语音能不能
安全地完成核心流程？凡是答案是“要看屏幕”或“听不到”的，都算不足。

## 本次发现并修补的不足

1. **风险提示会被转弯丢掉（v0.4 引入的 bug）**：v0.4 的冲突规则
   不分优先级，避障提示在转弯播报时直接丢弃。盲人可能因此听不到
   危险警告。修：只有低优先级冲突指令才丢弃；高优先级避障提示
   打断转弯，低优先级转弯在避障进行时丢弃。有测试。
2. **状态播报是英文枚举名**：`_stateText` 对 listening /
   understanding / planning / waitingConfirmation / degraded 等状态
   回退到 `state.name`，语音会读出 understanding、paused。修：
   全部状态给中文名；演示界面状态行也改用中文名，屏幕阅读器
   不再读英文。旧 Widget 测试同步改成中文断言。
3. **“停下”说不出来**：解析只认“暂停 / 停一下 / 先停下”，
   “停下”“别走了”不认；“我在哪”也不认。修：解析加
   “停下、别走、我在哪”，停下即暂停导航、停直行计时器。
4. **室内步骤、录像只能点按钮**：盲人到服务台后不能语音确认，
   任务完成后不能语音保存/删除录像。修：新增“确认 / 我到了 /
   下一步”推进室内步骤（只在室内引导状态有效，其他状态不乱
   推进无关任务）；新增“保存录像 / 删除录像”语音指令，只在
   等待确认状态有效，否则语音回答原因；录像保存语音明确说
   “不是已存入手机相册”。
5. **不知道前面有什么**：没有“前面有什么”指令。修：新增
   环境查询指令，有风险时报障碍文本，无风险时报感知文本，
   没有感知帧时如实说尚未模拟感知帧，不编造。
6. **紧急备用办法只显示不播报**：紧急语音只有一句“已进入紧急
   求助流程”，备用办法（大声呼喊、拨打紧急联系人、原地停留）
   只在屏幕上。修：紧急播报全文含备用办法，并再次说明
   尚未确认联系到任何帮助站。
7. **健康降级只显示不播报**：地图桩、演示语音、无摄像头等
   降级只在屏幕健康行。修：任务开始时语音播报健康降级提示。
8. **状态查询不含路线**：“现在到哪了”只报状态名和当前提示。
   修：状态播报追加已规划路线信息（未规划时不加）。
9. **界面标题版本滞后**：App 标题还是 v0.2。修：改为 v0.5。

## 本次审计确认、但本版仍做不到的（不冒充）

- 真实系统 TTS/ASR、摄像头、GPS、高德、YOLO、实地核验、
  真实道路安全、真实盲人用户实测：仍未验证，见 DEFECTS.md。
- 医院完整挂号、车站、路口放行、云端传图、持续唤醒词、
  呼叫帮助站、保存到相册：v0.4 已删除，本版不恢复。
- 风险仍在时没有周期性重复停下提醒：障碍提示是一次性的，
  过期后不再重复。本版不擅自加重复提醒（会干扰高优先级
  语音），留给真机阶段按盲人用户实测决定节奏。
